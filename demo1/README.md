# 增强版本地 RAG 知识库系统

一个功能完整的本地 RAG（检索增强生成）系统，支持实时监控、向量化过程可视化和相似度控制。

## 🚀 新增功能

### 1. 向量化实时过程监控
- **实时进度显示**：文档向量化过程的实时进度条
- **详细状态信息**：显示当前正在处理的文档名称和进度
- **向量维度信息**：显示生成的向量维度信息

### 2. 相似度阈值控制
- **可调节阈值**：通过滑块控制相似度阈值（0.0-1.0）
- **Top-K 控制**：可调节返回的最相关文档数量（1-10）
- **实时参数显示**：参数变化实时反映在界面上

### 3. 向量匹配过程可视化
- **检索详情展示**：显示每次检索的详细信息
- **相似度分数**：精确到小数点后4位的相似度分数
- **匹配过程可视化**：通过进度条显示各文档的相似度排序
- **查询向量信息**：显示查询向量的维度和前10维数值

### 4. 增强的检索过程展示
- **搜索时间统计**：显示向量检索的耗时
- **文档来源追踪**：清晰显示每个结果的文档来源
- **上下文预览**：在聊天界面中显示检索到的文档片段

## 🎯 系统架构

```
用户查询 → 向量化 → 相似度计算 → Top-K 筛选 → 阈值过滤 → 上下文生成 → LLM 回答
    ↓         ↓         ↓           ↓         ↓         ↓         ↓
实时监控   进度显示   匹配可视化   参数控制   结果展示   详情显示   智能回答
```

## 📊 监控界面说明

### 实时监控面板
1. **向量化进度**：显示文档向量化的实时进度
2. **最近检索**：显示最近一次检索的详细信息
3. **向量匹配**：可视化显示向量相似度匹配过程

### 参数控制面板
1. **Top-K 文档数**：控制检索返回的文档数量
2. **相似度阈值**：设置最低相似度要求

### 系统信息面板
1. **文档数量**：当前知识库中的文档总数
2. **向量维度**：嵌入向量的维度信息
3. **系统状态**：实时系统运行状态

# 访问 Web 界面
http://localhost:3000

## 📋 使用说明

1. **上传文档**：拖拽或选择 .txt 文件上传到知识库
2. **调整参数**：根据需要调整 Top-K 和相似度阈值
3. **提问交互**：在聊天界面输入问题
4. **监控过程**：观察右侧监控面板的实时信息
5. **查看详情**：在聊天消息中查看检索详情

## 🔍 检索过程详解

### 1. 查询向量化
- 用户输入 → Ollama 嵌入模型 → 查询向量
- 实时显示：向量维度、前10维数值

### 2. 相似度计算
- 查询向量 vs 所有文档向量
- 使用余弦相似度算法
- 实时显示：每个文档的相似度分数

### 3. Top-K 匹配
- 按相似度排序所有文档
- 选择前 K 个最相关文档
- 实时显示：排序过程和选择结果

### 4. 阈值过滤
- 过滤低于阈值的文档
- 确保结果质量
- 实时显示：过滤前后的文档数量

## 🔧 配置选项

### Ollama 配置
- LLM 模型：llama3.1
- 嵌入模型：nomic-embed-text
- 服务地址：http://localhost:11434

### 检索参数
- 默认 Top-K：3
- 默认相似度阈值：0.0
- 文本分块大小：600
- 分块重叠：100
